Rosk APT repository

Rosk: quick tasks and notes for GNOME, synced with Google Tasks and Keep. Needs GNOME 48 or newer (Ubuntu 25.04+, Debian 13+). Source: github.com/miamibc/rosk.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://miamibc.github.io/rosk/rosk-archive-keyring.gpg | sudo tee /etc/apt/keyrings/rosk.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/rosk.gpg] https://miamibc.github.io/rosk stable main" \
  | sudo tee /etc/apt/sources.list.d/rosk.list
sudo apt update
sudo apt install rosk

Updates then come with sudo apt upgrade. Or download the latest package directly: rosk_0.2.0_all.deb.
