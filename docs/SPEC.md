# Rosk — продуктовая спецификация

## 1. Идея

Rosk — это «записал и вычеркнул». Главные качества: **скорость** (от мысли до сохранённой задачи
меньше 3 секунд) и **краткость** (интерфейс не отвлекает, ничего лишнего).

Целевая платформа: GNOME (Wayland), Ubuntu 26.04+, GNOME Shell 50+.

## 2. Объекты

### 2.1 Задача (Task)

Хранится в Google Tasks. Поддерживается всё, что даёт Tasks API (см. GOOGLE_APIS.md §2):

- заголовок, описание (notes);
- статус выполнено / не выполнено, дата выполнения;
- срок (`due`, deadline) — только дата, синхронизируется с Google (ADR-006);
- подзадачи — один уровень (как в Google);
- порядок (drag & drop), перенос между списками;
- ссылки-источники (`links`), `webViewLink`, назначение из Docs/Chat — только отображение;
- скрытые/очищенные выполненные задачи.

Время срока, напоминания, повторение и звёздочка есть в приложениях Google, но не в публичном
API. В первой версии их нет; поддержка — после исследования внутреннего API Google (ROADMAP M7).
Ссылка-источник (например, на письмо Gmail) показывается чипом, как в мобильном приложении.

### 2.2 Заметка (Note)

Аналог Google Keep: заголовок, текст **или** чек-лист (пункты с отметкой, один уровень вложенности),
закрепление, цвет, метки, архив, корзина.

Синхронизируются с Google Keep через `gkeepapi` (ADR-004). Пока Keep не подключён или недоступен —
заметки работают локально и отправляются позже.

### 2.3 Списки и категории

- Задачи группируются по **спискам** Google Tasks (1:1).
- Заметки группируются по **меткам** Keep.
- В интерфейсе это единая боковая панель «Категории», но у каждой категории есть тип
  (список задач / метка заметок). **В Google они никогда не смешиваются**: задача всегда уходит
  в Tasks, заметка — в Keep.
- Преобразование задача <-> заметка — только явным действием пользователя («Превратить в заметку»):
  создаётся объект в другом сервисе, исходный удаляется.

## 3. Функциональные требования

### F1. Быстрый ввод из панели GNOME

- **Индикатор в верхней панели** (расширение GNOME Shell): иконка Rosk со счётчиком задач
  «пора делать» (просрочено + сегодня). Клик — выпадающее окно:
  - поле ввода в фокусе сразу;
  - Enter — сохранить и закрыть; Shift+Enter — сохранить и остаться (ввод серии задач);
  - Esc — закрыть;
  - под полем — короткий список «Сегодня / просрочено» с чекбоксами (вычеркнуть в один клик);
  - ссылка «Открыть Rosk».
- **Глобальная горячая клавиша** (по умолчанию `Super+Alt+R`, настраиваемая) — открывает то же
  окно быстрого ввода.
- **Поиск GNOME** (search provider): поиск по задачам и заметкам из обзора, Enter открывает объект.
- Быстрый ввод работает без сети и без запущенного главного окна.

### F2. Синтаксис быстрого ввода

Одна строка, всё опционально, разбор на лету с подсветкой распознанных частей:

| Ввод | Значение |
|---|---|
| `Позвонить в банк` | задача в список по умолчанию |
| `#работа` | список (автодополнение; неизвестный — предложить создать) |
| `сегодня`, `завтра`, `послезавтра`, `пн`..`вс`, `12.12`, `12 дек`, `через 3 дня` | срок-дата |
| `n:` в начале | заметка вместо задачи (`n: идея для статьи`) |
| `- ` в строке после `:` | подзадачи/пункты: `Поездка: - билеты - отель` |

Языки разбора: русский и английский. Распознанный фрагмент можно отменить (Backspace по чипу) —
тогда он остаётся текстом заголовка.

### F3. Главное окно

Боковая панель (умные представления + категории) и основная область.

Умные представления:

1. **Сегодня** — просроченные + срок сегодня, сортировка по времени.
2. **Предстоящие** — сгруппировано по дням (7 дней) и далее «Позже».
3. **Все задачи** — все списки, сгруппировано по спискам.
4. **Заметки** — сетка/список карточек Keep-подобно, закреплённые сверху.
5. **Выполненные** — архив выполненных, по дате выполнения.

Категории: списки задач и метки заметок, счётчики, создание/переименование/удаление.

Строка задачи: чекбокс, заголовок, однострочный фрагмент notes (приглушённо), чип срока,
индикатор подзадач (`2/5`), чип источника (например, письмо Gmail).
Подзадачи раскрываются под родителем.

Редактирование: inline-редактирование заголовка по клику; детали — боковая панель справа
(описание, срок, подзадачи, список, ссылки, «открыть в Google»).

### F4. Подсветка сроков

| Состояние | Признак | Вид |
|---|---|---|
| Просрочено | дата срока прошла | красный чип, задача поднимается вверх |
| Сегодня | срок сегодня | акцентный (оранжевый) чип |
| Завтра / скоро | 1–3 дня | обычный чип |
| Позже | > 3 дней | приглушённый чип |

Формат чипа — относительный и короткий: `вчера`, `сегодня`, `завтра`, `пт`, `12 дек`.

### F5. Вычёркивание

- Отметка выполнения — анимация зачёркивания (~300 мс), затем задача уходит в «Выполненные».
- Отмена через тост «Выполнено · Отменить» (5 с).
- Выполнение родителя отмечает все подзадачи (как в Google).

### F6. Уведомления

- Утренняя сводка в настраиваемое время: «Сегодня 5 задач, 2 просрочены».
- Действия в уведомлении: «Открыть», «Перенести просроченные на сегодня».
- Напоминания на конкретное время — после ROADMAP M7.
- Работает фоновая служба Rosk (автозапуск при входе, без окна).

### F7. Оффлайн и синхронизация

- Все операции выполняются над локальной базой мгновенно; сеть никогда не блокирует UI.
- Изменения копятся в очереди и отправляются при появлении сети.
- Индикатор состояния синхронизации: «синхронизировано», «N изменений ждут отправки»,
  «ошибка» (с подробностями и кнопкой повторить).
- Конфликты разрешаются автоматически (ARCHITECTURE.md §5); потерянные версии доступны в
  истории объекта.

### F8. Поиск и клавиатура

- `Ctrl+F` — поиск по заголовкам, описаниям, пунктам чек-листов.
- `Ctrl+N` — новая задача в текущем представлении; `Ctrl+Shift+N` — новая заметка.
- `Space` — выполнить выделенную; `Delete` — удалить (с отменой); `Ctrl+1..5` — представления;
  `Enter` — редактировать; стрелки — навигация. Всё приложение управляемо без мыши.

### F9. Настройки

Аккаунт (из GOA, выбор при нескольких Google-аккаунтах), список по умолчанию, горячая клавиша,
уведомления и время утренней сводки, адаптер Keep
(вход / выход, состояние),
тема (системная / светлая / тёмная).

## 4. Нефункциональные требования

- **Скорость**: окно быстрого ввода появляется < 150 мс (оно живёт в процессе GNOME Shell);
  главное окно < 500 мс при запущенной фоновой службе; любые действия в UI < 50 мс.
- **Надёжность**: ни одно изменение пользователя не теряется (транзакционная локальная БД,
  очередь операций переживает падение и перезагрузку).
- **Приватность**: токены — только через GOA / libsecret; данные — в `~/.local/share/rosk`;
  никакой телеметрии.
- **Дизайн**: GNOME HIG, libadwaita, адаптивность до ширины 360 px, тёмная тема, акцентный цвет
  системы, минимум рамок и иконок.
- **Локализация**: русский и английский (gettext).
- **Объём данных**: комфортная работа с 5 000 задач и 2 000 заметок.

## 5. Вне рамок первой версии

Совместный доступ к заметкам, вложения/картинки в заметках (только просмотр, если Keep отдаёт),
рисунки, голосовые заметки, мобильные клиенты, другие провайдеры (Todoist, CalDAV).
